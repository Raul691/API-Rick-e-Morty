# Rick and Morty - Explorador de Personagens

Projeto desenvolvido para a disciplina **Web Development Front-End**, utilizando HTML, CSS e JavaScript puro.

## Sobre o projeto

O site permite explorar personagens do universo Rick and Morty por meio do consumo da API pública oficial.

## Funcionalidades

- Listagem dinâmica de personagens.
- Pesquisa por nome.
- Filtro por status (vivo, morto ou desconhecido).
- Paginação dos resultados.
- Sistema de favoritos.
- Armazenamento dos favoritos no navegador utilizando LocalStorage.
- Layout responsivo.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Fetch API
- DOM Manipulation
- LocalStorage

## API utilizada

[The Rick and Morty API](https://rickandmortyapi.com/)

## Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.
4. Certifique-se de estar conectado à internet para carregar os dados da API.
